Kebijakan Privasi

MailCraft adalah aplikasi web untuk mendesain email dan mengirimnya dari akun Gmail milik pengguna sendiri.

Data yang diakses dari akun Google

  • Alamat email akun Google-mu, hanya untuk menampilkan akun yang terhubung dan mengisi kolom pengirim.
  • Izin kirim email (gmail.send), hanya untuk mengirim email yang kamu susun sendiri, ke penerima yang kamu tentukan, saat kamu menekan tombol kirim.

MailCraft tidak membaca, menyimpan, atau menghapus isi inbox-mu dan tidak meminta izin untuk itu.

Di mana data disimpan

Desain email, daftar penerima, dan gambar disimpan di browser-mu sendiri (localStorage). Token akses Google disimpan sementara di sessionStorage dan hilang saat tab ditutup atau setelah ±1 jam. Tidak ada server MailCraft yang menerima data tersebut. Email dikirim langsung dari browser ke Gmail API milik Google.

Berbagi data

Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan. Penggunaan data dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses

Klik “Putuskan” di MailCraft, atau cabut akses kapan saja di myaccount.google.com/permissions. Untuk menghapus draf, gunakan Pengaturan → Reset draf atau hapus data situs di browser.
